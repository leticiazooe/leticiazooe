## Sobre mim

Sou formada em **Análise e Desenvolvimento de Sistemas** pela FATEC Taquaritinga, pós-graduanda em **Engenharia de Controle e Automação** e atualmente atuo como **Desenhista Industrial / Mechanical Designer**.

Minha trajetória profissional conecta desenvolvimento de software, automação de processos, análise de dados e engenharia industrial. Gosto de compreender problemas reais, estruturar requisitos e transformar necessidades operacionais em soluções funcionais, documentadas e aplicáveis.

Ao longo da minha experiência, já trabalhei com:

- desenvolvimento de processos, formulários, widgets, portais e relatórios na plataforma **Fluig**;
- modelagem de processos com **BPMN**, gestão documental com **ECM** e integrações com APIs;
- desenvolvimento front-end com **HTML, CSS, JavaScript, jQuery, React e TypeScript**;
- consultas, integrações e modelagem de dados com **SQL Server e PostgreSQL**;
- dashboards, indicadores e transformação de dados com **Power BI e ETL**;
- modelagem 3D, detalhamento 2D, desenho técnico e documentação de projetos industriais.

## Projetos em destaque

### Atrix PDM

Sistema de gestão documental para projetos CAD, desenvolvido para centralizar e controlar arquivos técnicos ao longo de seu ciclo de vida.

**Principais recursos:** controle de versões, check-in e check-out, bloqueio de edição, permissões, workflow de aprovação, histórico, cópias controladas, BOM, OCR, visualização de arquivos e rastreabilidade.

`Python` `HTML` `CSS` `JavaScript` `SQL` `WebView2` `BPMN` `CAD`

### Interactive Database Schema Explorer

Aplicação local-first para importar scripts SQL Server, interpretar estruturas de banco de dados e gerar diagramas relacionais interativos, com busca, filtros, inspeção de metadados, navegação entre relacionamentos e exportação.

`React` `TypeScript` `Vite` `Web Workers` `SQL Server` `Diagramas ER`

### Interactive BPMN Process Explorer

Plataforma para importar, interpretar, visualizar, analisar, documentar e editar diagramas BPMN, permitindo explorar atividades, eventos, gateways, participantes, raias, conexões e artefatos de maneira interativa.

`React` `TypeScript` `BPMN 2.0` `XML` `SVG` `Processos`
